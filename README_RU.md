# CHESS REBASE 0.2.0 — захват экрана

В этой версии добавлен реальный запрос Android MediaProjection и foreground service для захвата экрана. После системного согласия приложение получает кадры экрана и сохраняет последний кадр в приватный кеш приложения (`cache/latest_screen.png`), обновляя его примерно раз в 1,2 секунды. Android показывает постоянное уведомление, пока захват активен.

## Уже реализовано
- Kotlin Android-приложение;
- запрос разрешения MediaProjection;
- foreground service с типом `mediaProjection` (Android 14+);
- получение кадров через `ImageReader`;
- сохранение последнего кадра в кеш приложения;
- отдельный тестовый overlay для проверки разрешения поверх окон;
- SH-файл запуска установленного APK.

## Пока НЕ реализовано
- автоматический поиск шахматной доски на кадре;
- распознавание фигур и стороны пользователя;
- шахматный алгоритм и выбор сильного хода;
- привязка координат стрелки к клеткам доски.

Зелёная стрелка в этой версии демонстрационная, не является подсказкой и не должна использоваться в партии.

## Сборка
Откройте проект в Android Studio (JDK 17+, Android SDK 35, Gradle plugin из build.gradle.kts) и выполните Build > Build APK(s). На устройстве установите APK, выдайте разрешение «Поверх других приложений», затем нажмите «Начать захват экрана» и подтвердите системный запрос Android.

## Проверка
После старта переключитесь в другое приложение. Захват продолжится в фоне, пока активен системный индикатор/уведомление. Остановка — кнопка «Остановить захват и стрелку» либо системная остановка захвата.

## Важно
MediaProjection требует явного согласия пользователя. Root не отменяет это требование. Android может запрещать захват защищённого содержимого (`FLAG_SECURE`). Это исходный код, APK здесь не собран и работа на конкретном POCO M6 Pro не проверена.
