# Сборка CHESS REBASE в Codemagic

## Что это

`codemagic.yaml` настраивает облачную сборку отладочного APK. Локальная установка Android Studio и Android SDK на Kali не нужна.

## Важно о текущем приложении

Это ранний технический прототип: он содержит сервис захвата экрана и тестовый слой стрелки. Распознавание шахматной доски, определение стороны и вычисление сильного хода ещё не реализованы. Успешная сборка APK не означает, что эти функции уже работают.

## Как собрать

1. Распакуйте ZIP.
2. Создайте пустой репозиторий на GitHub.
3. Загрузите **содержимое папки** `chess_rebase_android` в корень репозитория (файл `codemagic.yaml` должен лежать в корне рядом с `settings.gradle.kts`).
4. Войдите на https://codemagic.io/ и подключите этот GitHub-репозиторий.
5. Выберите Android / Native Android, если сервис попросит тип проекта.
6. Codemagic найдёт `codemagic.yaml`. Выберите workflow `chess-rebase-android-debug` и нажмите Start new build.
7. После успешной сборки скачайте APK из раздела Artifacts. Для первого теста это debug APK.

## Примечание

Workflow генерирует Gradle Wrapper на облачной машине (Gradle 8.9), затем выполняет `assembleDebug`. Это позволяет не хранить wrapper JAR в архиве. Если образ Codemagic не содержит команду `gradle`, сборка остановится на шаге проверки; тогда нужно будет переключить конфигурацию на установленный в образе Gradle или добавить wrapper.
